# 📜 Code of Conduct / Código de Conducta
## Cortex-Protocol & Neuro-Synapse Core

## 🤝 Our Pledge / Nuestro Compromiso

**[EN]** We pledge to make participation a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity, experience, nationality, appearance, race, religion, or sexual identity.

**[ES]** Nos comprometemos a hacer de la participación una experiencia libre de acoso para todos, independientemente de edad, tamaño corporal, discapacidad, etnia, identidad de género, experiencia, nacionalidad, apariencia, raza, religión o identidad sexual.

## ✅ Our Standards / Nuestros Estándares

**[EN]** Positive behavior: / **ES:** Comportamiento positivo:

| Positive / Positivo | Description / Descripción |
|---------------------|---------------------------|
| 🌟 Welcoming language | Welcoming and inclusive language / Lenguaje acogedor e inclusivo |
| 🤝 Respect | Respect different viewpoints / Respetar diferentes puntos de vista |
| 🛠️ Constructive criticism | Accept constructive criticism / Aceptar críticas constructivas |
| 🎯 Community focus | Focus on what's best for community and patients / Enfocarse en lo mejor para la comunidad y los pacientes |
| 💙 Empathy | Show empathy / Mostrar empatía |

**[EN]** Unacceptable behavior: / **ES:** Comportamiento inaceptable:

| Unacceptable / Inaceptable | Description / Descripción |
|---------------------------|---------------------------|
| 🚫 Sexualized content | Sexualized language or imagery, unwelcome sexual attention / Lenguaje o imágenes sexualizadas, atención sexual no deseada |
| 🚫 Trolling & attacks | Trolling, insulting comments, personal or political attacks / Trolling, comentarios insultantes, ataques personales o políticos |
| 🚫 Harassment | Public or private harassment / Acoso público o privado |
| 🚫 Doxxing | Publishing others' private information without permission / Publicar información privada de otros sin permiso |

## 🏥 Project-Specific Standards / Estándares Específicos

**[EN]** Given mental health data, additional standards:  
**[ES]** Dados los datos de salud mental, estándares adicionales:

| # | Standard / Estándar |
|---|---------------------|
| 1 | **Real patient data never shared** in issues, PRs, discussions, chats. / **Nunca se comparten datos de pacientes reales** en issues, PRs, discusiones, chats. |
| 2 | **Clinical case discussions** use completely anonymized, fictional info. / **Discusiones de casos clínicos** usan información completamente anonimizada y ficticia. |
| 3 | **Professional secrecy** applies in technical conversations. / **El secreto profesional** aplica en conversaciones técnicas. |
| 4 | **Technical decisions** evaluated by ethical impact, not just code elegance. / **Las decisiones técnicas** se evalúan por impacto ético, no solo elegancia de código. |

## 👤 Responsibilities / Responsabilidades

**[EN]** Maintainers clarify acceptable behavior standards and take appropriate corrective action. Maintainers can remove, edit, or reject contributions not aligned with this Code, or ban contributors for inappropriate, threatening, offensive, or harmful behavior.

**[ES]** Los mantenedores clarifican estándares de comportamiento aceptable y toman acciones correctivas apropiadas. Los mantenedores pueden eliminar, editar o rechazar contribuciones no alineadas con este Código, o prohibir colaboradores por comportamiento inapropiado, amenazante, ofensivo o dañino.

---

## 🌐 Scope / Alcance

**[EN]** Applies within project spaces and public spaces when representing the project.  
**[ES]** Aplica dentro de los espacios del proyecto y espacios públicos cuando se representa el proyecto.

---

## 🚨 Enforcement / Aplicación

**[EN]** Report abuse via GitHub private issue. All complaints reviewed and investigated.  
**[ES]** Reportar abuso vía issue privado de GitHub. Todas las quejas serán revisadas e investigadas.
